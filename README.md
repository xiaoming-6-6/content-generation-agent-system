# AI 内容创作工具 

## 项目简介

AI Content Factory 是一个轻量级多智能体内容生成系统，用于探索基于 Agent 协同的自动化内容生产流程。

系统通过多个功能智能体协作，实现从选题发现、内容生成到风格优化的完整流水线，可面向不同内容平台自动生成适配内容。

目前主要用于多 Agent 协同机制实验，以及内容自动化生成场景验证。

---

## 系统架构

项目由三个核心智能体组成：

### Trend Agent（热点分析）

负责围绕输入主题生成具有传播潜力的内容选题。

### Content Agent（内容生成）

负责根据选题生成结构化内容。

### Style Agent（风格优化）

负责调整语言风格、增强表达效果，并适配不同平台调性。

---

## 工作流程

热点分析 → 内容生成 → 风格优化 → 输出结果

---

## 核心功能

* 多智能体协同生成
* 自动化内容生产流水线
